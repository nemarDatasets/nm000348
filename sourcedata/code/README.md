# This is a code script used to verify WBCIC_SHU Motor Imagery dataset.

1.Researcher will download the dataset first, and save all the files of the dataset in ./code/shu_data/.
2. The file of Deep_learning include FBCNet toolbox that contains three deep learning algorithms: FBCNet, eegNet, and deepConvNet.
3. The file of Machine_learning include CSP and FBCSP.
4. The Readme.txt in each algorithm describes the basic usage of the script.
5. If an error is reported during program execution, please check the running path. It is recommended that users open the algorithm path to run.
