# Demo to show how to run the deeplearning method

1. Process the preprocessed data through "transform.py" to ensure it conforms to the format required for running the code.
2. Enter the path from step 1 into ".\code\Deep_learning\FBCNet\codes\centralRepo\saveData.py" 
3. Afterwards, you can run cv.py.
4. The "Parameters" in "Run/Debug Configurations" can be used to modify the dataset and network, where 2 represents this dataset. 
The available networks to choose from are FBCNet, eegNet, and deepConvNet.
